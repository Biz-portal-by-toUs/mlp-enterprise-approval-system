S3 Presigned Upload 테스트 (localStorage 토큰 포함)

흐름: 파일 선택 → /presign(Authorization 포함) → S3 PUT(Authorization 없음) → /complete(Authorization 포함)
• 같은 도메인에서 백엔드가 떠 있으면 API_BASE="" 그대로 사용
• 토큰은 localStorage에서 자동으로 찾고(accessToken/token/jwt/Authorization), 안 맞으면 Token Key를 바꿔줘
• auto면 자동 탐색
• 값이 Bearer xxx 형태면 그대로 쓰고, 아니면 자동으로 Bearer를 붙임
